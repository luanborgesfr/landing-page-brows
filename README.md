# Coxinha dos Brows

Site oficial da Coxinha dos Brows, uma empresa de salgados artesanais em São Miguel do Guamá, no Pará. Este projeto foi desenvolvido para a presença digital real da empresa e para facilitar que clientes conheçam os produtos e entrem em contato para fazer pedidos.

## Sobre o site

A página apresenta os produtos e diferenciais da Coxinha dos Brows, avaliações de clientes e informações de localização e funcionamento. A navegação permite acessar as diferentes seções, e os botões de pedido direcionam para uma conversa no WhatsApp da empresa.

## Tecnologias

- HTML
- CSS
- JavaScript

## Executar localmente

Abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências.
